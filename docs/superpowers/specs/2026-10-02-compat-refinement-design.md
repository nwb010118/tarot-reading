# 궁합 정교화 설계

- 점수: 유형별 기본 점수(문구와 유형 이름은 그대로)에 추가 관계의 가감점을 더해 20~99점으로 클램프한다. `js/compat-score.js`.
  - 별자리: 두 별자리 간격 0~6칸 (1칸 -8, 2칸 +3, 3칸 -6, 4칸 +4, 5칸 -6, 0·6칸 0).
  - 띠: 원진 -8, 육해 -6 (겹치면 원진만).
  - 사주: 일간 천간합 +10, 일지 육합 +8 / 삼합 +5 / 충 -10 / 해 -5.
- 띠 경계: 설날(음력 1월 1일) 기준. 띠운세·띠 궁합에 선택 입력 "생일" 추가, 설날 이전이면 전년도 띠. 변환표(~2050) 밖이면 출생연도만. `js/ddi-boundary.js`.
- 근거 공개 패널에 기본 점수, 가감 내역, 최종 점수, 경계 안내를 표시한다.
- 범위 밖: 궁합 문구 변경, 사주 궁합의 월지·시주·신살, 공유 링크의 띠 경계.
