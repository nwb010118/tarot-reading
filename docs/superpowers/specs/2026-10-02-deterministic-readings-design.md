# 고정 결과 + 오늘의 한 장 + 근거 공개 설계

작성일: 2026-10-02 / 대상: 점집 SPA (정적 사이트, 서버 없음)

## 배경과 목표

리딩 문구, 키워드, 조언, 타로 카드가 `Math.random`으로 뽑혀 같은 조건으로 다시 눌러도 결과가 달라진다. 신뢰와 재방문에 불리하다. 이 설계는 결과를 시드 기반으로 고정하고, 하루 한 장 카드와 계산 근거 공개를 추가한다.

로드맵(별도 설계): ② 리딩 일기·연속 방문 ③ 공유 카드 ④ 궁합 정교화 ⑤ 점집 주인의 목소리 ⑥ 영어판 ⑦ 브랜드 ⑧ 규칙 기반 질문 해석. 이 문서는 ①만 다룬다.

## 범위 밖

서버·계정·푸시 알림, 궁합 점수 개편, 공유 이미지, 문구 톤 변경, 입춘·설날 경계 보정.

## 1. 시드 난수 모듈 `js/seeded-random.js`

- `hashString(str)`: 문자열을 32비트 정수로 만든다.
- `createRng(parts)`: `parts` 배열을 `|`로 이어 해시한 뒤 mulberry32로 `() => [0,1)` 함수를 돌려준다.
- `todayKey(now)`: 기기 현지 날짜 `YYYY-MM-DD`.
- `getDeviceId(storage)`: `localStorage`에 익명 ID를 한 번 만들어 저장. 저장소를 못 쓰면 메모리 임시값.
- 브라우저 전역과 `module.exports`를 둘 다 지원하는 기존 파일들의 패턴을 따른다.

## 2. 모드별 시드 정책

| 모드 | 시드 구성 | 결과 |
|---|---|---|
| 별자리 | zodiac, 별자리 키, 날짜, 주제, 하위선택, 기간 | 하루 고정 |
| 띠 | ddi, 띠(출생연도), 날짜, 주제, 하위선택, 기간 | 하루 고정 |
| 사주 | saju, 생년월일시·성별·음양력·윤달·시간모름, 주제, 하위선택, 기간 | 날짜와 무관하게 고정 |
| 궁합 | compat, 유형, 두 사람 입력값 | 고정 |
| 타로 리딩 | 시드 없음 (`Math.random`) | 뽑을 때마다 다름, 횟수 무제한 (현행 유지) |
| 오늘의 한 장 | today-card, 기기 ID, 날짜 | 하루 고정 (4절) |

`app.js`의 `pickRandom`, `pickKeywords`, `resolveMeaningText`, `pickAdvice`, 사주·궁합 쪽 선택 함수는 `rng` 인자를 받도록 바꾸고, 각 리딩 시작 시 위 시드로 만든 `rng` 하나를 내려보낸다. 인자가 없으면 기존처럼 `Math.random`을 쓴다(기존 테스트 호환).

## 3. 타로 리딩

실제 타로처럼 뽑을 때마다 다른 카드가 나오는 것이 자연스러우므로 현행 무작위 동작을 유지한다. 다시 뽑기는 무제한이며 별도 상태 저장이 없다. 이 절은 변경 사항이 없음을 명시하기 위해 둔다.

## 4. 오늘의 한 장

- 홈 화면 상단 카드. 시드는 `today-card`, 기기 ID, 날짜. `drawCards(deck, 1, rng)`로 한 장.
- 표시: 카드 이미지, 카드 이름, 정/역방향, 카드의 키워드와 조언 (그림 해설 파일은 53KB라 홈 화면에 싣지 않음), 해당 카드 백과사전 페이지 링크.
- 하루 종일 같고, 다시 뽑기 없음. 기록(history)에는 저장하지 않는다.

## 5. 근거 공개 패널

결과 아래에 접이식 `<details>` "이 풀이는 어떻게 나왔나요?"를 둔다. 이미 계산된 값만 보여준다.

- 타로: 뽑힌 카드·방향·자리, "카드는 78장 덱에서 무작위로 뽑았고, 정방향과 역방향은 각각 절반의 확률입니다." (오늘의 한 장은 "오늘 날짜와 이 기기를 기준으로 뽑았어요")
- 별자리: 별자리와 날짜 범위. 띠: 출생연도와 띠.
- 사주: 일간, 오행, 음양(명식 계산에서 이미 나오는 값).
- 기존 `renderPracticePlan`의 안내 "리딩 문장은 준비된 해석 중 무작위로 선택됩니다"를 새 정책 설명으로 교체한다.

## 6. 오류 처리

- `localStorage` 불가: 메모리 임시 ID, 다시 뽑기 횟수는 새로고침 전까지만 유지.
- 해시 입력에 `undefined`가 섞이지 않도록 모든 부품을 문자열로 정규화한다.

## 7. 테스트

- `tests/seeded-random.test.js`: 같은 parts는 같은 수열, 다른 parts/날짜는 다른 수열, 분포가 [0,1) 안, `todayKey` 형식, `getDeviceId`가 저장소 없이도 동작.
- 시드 `rng`를 쓴 `drawCards`가 같은 시드에서 같은 카드(오늘의 한 장에 사용).
- 선택 함수들에 같은 `rng`를 주면 같은 문구, 인자 없으면 기존 동작.
- 기존 24개 테스트 파일 전부 통과, `tests/reading-guidance-ui.test.js`의 안내 문구 단언은 새 문구에 맞게 수정.
- 4개 모드(타로·별자리·띠·사주)와 궁합을 브라우저에서 눌러 오류가 없는지 확인한 뒤 push(공유 설정 변경 교훈).

## 8. 배포

`js` 변경 후 `npm run build:cache-version`. 새 스크립트는 `index.html`에 `app.js`보다 먼저 로드한다.
