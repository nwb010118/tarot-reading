## 목적

"점집" 앱은 서버·계정·결제가 없는 순수 정적 사이트지만, 사주/타로/별자리/궁합 등 운세 콘텐츠를 다루고 생년월일시·성별 같은 입력값을 다루는 만큼 개인정보처리방침·이용약관·면책조항을 갖춰 리스크를 낮춘다. 단, 이 문서와 구현은 일반적인 표준 관행을 따르는 것이며 법률 자문을 대체하지 않는다 — 실제 법적 리스크를 완전히 없애려면 변호사 검토가 필요하다는 점을 사용자에게 이미 안내했다.

## 사실관계 확인 (코드베이스 조사 완료, 문서 내용의 근거)

- `index.html`, `css/style.css`에 외부 스크립트·폰트·CDN·이미지 URL이 전혀 없음 (grep으로 확인) — 페이지 최초 로드 외에는 외부 네트워크 요청이 발생하지 않는다.
- 분석 도구(Google Analytics 등), 광고 스크립트, 추적 픽셀, 쿠키 사용 코드 없음.
- 사용자 입력(생년월일시, 성별, 궁합 상대방 정보 등)과 히스토리는 전부 `localStorage`에만 저장되며(`js/history-store.js`), 서버로 전송되는 지점이 코드 어디에도 없다.
- 히스토리 화면에 이미 "전체 삭제" 버튼이 존재해, 이용자가 언제든 저장된 데이터를 지울 수 있다.
- GitHub Pages로 호스팅되므로, 이 앱 자체는 데이터를 수집하지 않지만 GitHub의 인프라(예: 접속 로그)는 운영자 통제 밖에 있다 — 이 사실을 정직하게 고지한다.

이 사실관계가 개인정보처리방침의 "수집하는 개인정보 없음" 주장의 근거가 된다. 실제로 없는 걸 없다고 쓰는 것이므로 허위 기재 리스크가 없다.

## UI 통합

### 상시 노출 면책 문구

`index.html`의 `<header>` 바로 아래(`</header>` 다음, `<section id="screen-start">` 앞)에 추가:

```html
<p id="site-disclaimer">⚠ 재미로만 봐주세요 — 오락 목적이며 전문적인 법률·의료·재정·심리 상담을 대체하지 않습니다.</p>
```

모든 화면(시작 화면/결과 화면 공통)에서 보이도록 `#app` 안, `<header>` 바로 다음에 위치시켜 모드 전환과 무관하게 항상 노출한다.

### 푸터

`</div>` (`#app` 닫는 태그) 바로 앞에 추가:

```html
<footer id="site-footer">
  <a href="legal.html#privacy">개인정보처리방침</a>
  <a href="legal.html#terms">이용약관</a>
  <a href="legal.html#disclaimer">면책조항</a>
</footer>
```

## `legal.html` 구조

`index.html`과 별도의 정적 페이지. 기존 `css/style.css`를 그대로 재사용해 톤을 통일하고, 본문은 세 개의 `<section>`(각각 id `privacy`/`terms`/`disclaimer`)으로 구성해 앵커 링크로 바로 스크롤 이동 가능하게 한다. 맨 위에 "점집으로 돌아가기" 링크(`index.html`)를 둔다.

### 개인정보처리방침 (`#privacy`)

- 운영자가 개인(비영리, 개인 프로젝트)임을 명시
- **수집하는 개인정보: 없음.** 생년월일시·성별·궁합 상대방 정보 등 입력값은 이 기기의 브라우저(localStorage)에만 저장되며, 운영자를 포함한 어떤 서버로도 전송되지 않는다는 점을 명확히 기재(위 "사실관계 확인" 근거)
- 쿠키·분석 도구·광고·추적 스크립트를 사용하지 않는다는 점 명시
- 저장된 데이터는 "지난 기록 → 전체 삭제" 버튼 또는 브라우저 설정에서 이용자가 직접 삭제 가능하며, 브라우저 데이터를 지우면 함께 삭제된다는 점 안내
- GitHub Pages 호스팅 사실과, GitHub 자체의 접속 로그 등은 운영자 통제 밖이라는 점 + GitHub Privacy Statement 링크(`https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement`)

### 면책조항 (`#disclaimer`)

- 타로/별자리/띠운세/사주/궁합 콘텐츠는 전통 이론과 무작위 요소에 기반한 **오락 목적** 콘텐츠이며, 정확성·완전성·특정 목적 적합성을 보장하지 않음
- 법률·의료·재정·심리 상담 등 전문적 조언을 대체하지 않으며, 중요한 결정은 반드시 관련 전문가와 상담할 것을 권장
- 이용자가 본 서비스의 내용을 근거로 내린 판단이나 행동으로 인해 발생한 손해에 대해 운영자는 법이 허용하는 최대 범위에서 책임을 지지 않음
