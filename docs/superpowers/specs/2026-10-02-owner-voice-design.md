# 점집 주인의 목소리 설계

- 말투: 차분한 존댓말 "~어요", 짧은 문장, 단정하지 않는 톤.
- `data/voice.js`: 도입(타로/별자리/띠/사주/궁합/오늘의 한 장 각 4개), 마무리(일반 5, 건강 3, 투자 3). 같은 조건이면 같은 문구가 나오도록 시드로 고른다.
- 적용: 결과 제목 아래 도입 한 줄, 근거 패널 위 "주인의 한마디", 오늘의 한 장 카드.
- 건강, 투자 주제는 `getSensitiveReading`과 같은 조건으로 전용 마무리를 쓴다.
- 테스트: 종결어미, 길이, 단정 표현과 일본어 금지, 중복·유사도, 결정성.
- 범위 밖: 정적 페이지·가이드·약관·카드 백과사전 문구(애드센스 재검토 중), 2.5MB 본문 데이터 재작성, 캐릭터 이름·일러스트(7단계).
