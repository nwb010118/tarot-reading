# 정식 사주팔자(四柱八字) 모드 설계 문서

날짜: 2026-08-20

## 목적

기존 "점집" 앱(타로 / 별자리 / 띠운세 3모드)에 4번째 모드로 정식 사주팔자를 추가한다. 이전 세션에서는 절기·음력 계산의 정확도 리스크 때문에 사주를 보류하고 띠(12지신)로 축소했었는데, 이번엔 계산 정확도를 확보할 수 있는 방식(천문 공식 + 음양력 대조 테이블)을 찾아 정식으로 구현한다.

## 범위

- 생년월일시(양력/음력 선택 가능) + 성별을 입력받아 사주 4주(년주·월주·일주·시주)를 정확히 산출
- 대운(10년 주기 운세 흐름) 표 계산 및 표시 (간지+나이대만, 카테고리별 해설 문장은 없음)
- 기존 카테고리(11개)×기간(6개) 시스템을 재사용한 일간(日干) 기반 해설 + 오행 균형 수식어
- 태어난 시간을 모르는 사용자를 위한 "시간 모름" 옵션(시주·대운 생략, 3주만 계산)

범위 밖: 대운별 개별 해설 문장, 십성(十星)·신살(神殺) 등 심화 명리 이론, 궁합, 육십갑자 이외의 역법(음력 윤달 판정은 포함하되 그 외 특수 역법 없음).

## 계산 엔진 (`js/saju-calc.js`)

### 핵심 원리

사주의 년주/월주 경계는 절기(24절기 중 "절" 12개)로 정해지며, 이는 태양 황경(黃經)만으로 결정된다. 전체 24절기 테이블을 미리 만들 필요 없이, 다음 두 함수로 충분하다.

```
solarLongitude(date) -> λ (0~360도)
```
Meeus 저정밀 태양 좌표 공식(다항식+삼각함수, 외부 라이브러리 불필요, 정확도 약 0.01도 ≈ 오차 수 분 이내):
1. `T = (JD - 2451545.0) / 36525` (J2000 기준 율리우스 세기)
2. `L0 = 280.46646 + 36000.76983*T + 0.0003032*T^2` (평균 황경)
3. `M = 357.52911 + 35999.05029*T - 0.0001537*T^2` (평균 근점이각)
4. `C = (1.914602 - 0.004817*T - 0.000014*T^2)*sin(M) + (0.019993 - 0.000101*T)*sin(2M) + 0.000289*sin(3M)`
5. `theta = L0 + C` (진황경)
6. `Omega = 125.04 - 1934.136*T`, `lambda = theta - 0.00569 - 0.00478*sin(Omega)` (겉보기 황경, 도 단위, 0~360 정규화)

```
findSolarTermMoment(year, targetLongitude) -> Date
```
뉴턴법으로 `solarLongitude(t) == targetLongitude`가 되는 정확한 시각을 역산 (평균 변화율 약 0.9856도/일로 초기 추정 후 2~3회 반복이면 수렴). 입춘(315도)뿐 아니라 임의의 절 경계(대운 계산용)에도 재사용.

모든 계산은 KST(UTC+9) 기준. 타임존 선택 UI 없음.

### 4주 산출

- **월지**: `floor(((λ(생일시각) - 315 + 360) % 360) / 30)` → 0=인, 1=묘, …, 11=축. 24절기 테이블 없이 즉시 계산됨.
- **년주**: 생일이 그 해의 입춘(`findSolarTermMoment(year, 315)`) 이전이면 전년도를 "사주 연도"로 사용. `stemIdx = (사주연도 - 4) % 10`, `branchIdx = (사주연도 - 4) % 12` (갑=0…계=9, 자=0…해=11).
- **월간**: 오호둔 규칙표 — 년간 기준 인월(寅月) 시작 천간: 갑기→병, 을경→무, 병신→경, 정임→임, 무계→갑. 이후 월지가 인(0)에서 진행할 때마다 천간도 1씩 순환.
- **일주**: 율리우스일(JDN) 기반 60갑자 순환 공식. 기준일 보정은 구현 단계에서 공개적으로 검증 가능한 날짜(예: 잘 알려진 절기/명절의 일진) 2~3개와 대조해 캘리브레이션하고 테스트로 고정한다. 하루의 경계는 자정(00:00) 기준으로 단순화(야자시/조자시 구분 없음 — 범위 밖으로 명시).
- **시주**: 태어난 시:분을 12개 2시간 구간에 매핑(자시 23:00~01:00, 축시 01:00~03:00, …). 오둔법 규칙표 — 일간 기준 자시(子時) 시작 천간: 갑기→갑, 을경→병, 병신→무, 정임→경, 무계→임. 이후 시지가 자(0)에서 진행할 때마다 천간도 1씩 순환.
- **시간 모름**: 시주 계산을 생략하고 명식표에 "모름"으로 표시. 대운 계산도 생략 가능(대운은 시주와 무관하게 계산 가능하지만, 시간 모름 사용자에게 대운까지 보여주는 게 혼란스러울 수 있어 이 모드에서는 대운도 함께 숨긴다).

### 오행 분포

천간 오행: 갑을=목, 병정=화, 무기=토, 경신=금, 임계=수.
지지 오행: 인묘=목, 사오=화, 진술축미=토, 신유=금, 해자=수.
8글자(시간 모름이면 6글자) 중 오행별 개수를 집계. 최다 개수 원소가 3개 이상이면 "과다", 개수 0인 원소가 있으면 "부족", 둘 다 아니면 "균형"으로 분류(가장 극단적인 하나만 선택).

### 대운(大運)

- **순행/역행**: 년간의 음양(양간: 갑병무경임 / 음간: 을정기신계)과 성별의 조합으로 결정. 전통 규칙: (양간+남자) 또는 (음간+여자) → 순행, (음간+남자) 또는 (양간+여자) → 역행.
- **대운수**(첫 대운이 시작하는 나이): 순행이면 생일부터 다음 절입 순간까지, 역행이면 이전 절입 순간까지의 일수를 `findSolarTermMoment`로 구해서 3으로 나눈 값(나머지 처리 규칙은 구현 시 명리학 표준 반올림 관례를 따르고 테스트로 고정).
- **대운 간지 시퀀스**: 월주의 간지 쌍에서 시작해 순행이면 60갑자를 다음으로, 역행이면 이전으로 이어가며 10년 단위로 8~10개 구간 생성.
- **표시**: 간지 + 나이대(예: "정사대운 27~36세")만 표로 나열, 오늘 날짜 기준 현재 해당 구간을 강조 표시. 카테고리별 해설 문장은 붙이지 않는다.

## 음력 입력 지원

- 양력/음력 라디오 토글. 음력 선택 시 "윤달" 체크박스를 추가로 노출(같은 월이 평달/윤달로 겹치는 경우가 있어 이 정보 없이는 날짜가 모호함).
- `data/lunar-table.js`: 1900~2050년 음양력 대조 데이터. 자체 신월(新月) 천문 공식으로 계산하지 않고, 공신력 있는 출처(한국천문연구원 계열 공개 자료) 기반 데이터를 구현 단계에서 조사해 내장한다 — 음력 신월/윤달 판정을 자체 공식으로 재구현하면 미묘한 오차 위험이 크기 때문에, 사주 계산의 핵심인 절기 로직과 분리해 검증된 데이터 방식을 쓴다.
- `js/lunar-convert.js`(또는 `saju-calc.js`에 병합): 음력(연/월/윤달여부/일) → 양력 날짜 변환 함수. 변환된 양력 날짜를 위 4주 산출 로직에 그대로 입력.
- 지원 연도 범위 밖(1900년 이전/2050년 이후) 입력 시 에러 메시지로 안내하고 계산을 진행하지 않음.

## UI 흐름

- 모드 탭에 `사주` 추가 (`#mode-select`에 4번째 `.mode-btn`).
- `#saju-select` 블록(다른 모드와 마찬가지로 선택 시에만 노출):
  - 양력/음력 라디오
  - 음력 선택 시: 윤달 체크박스 노출
  - 생년월일 입력 (`<input type="date">`)
  - 시:분 입력 (`<input type="time">`) + "태어난 시간을 몰라요" 체크박스 → 체크 시 시간 입력 비활성화
  - 성별 라디오 (남/여)
- 기존 `#category-select` / `#period-select`는 그대로 재사용, 수정 없음.
- 결과 화면(`showSajuSummary`):
  1. 사주 명식표: 년주·월주·일주·시주 4열 × 천간/지지 2행 그리드 (시간 모름이면 시주 칸 "모름")
  2. 오행 분포 요약 (예: "목1 화2 토3 금1 수1")
  3. 대운 표 (시간을 아는 경우만; 현재 구간 강조)
  4. 카테고리+기간 기반 해설 문단 (일간 trait/카테고리 문장 + 오행 균형 수식어)

## 콘텐츠 (`data/saju-data.js`)

기존 `zodiac-data.js`/`ddi-data.js`와 동일한 구조 패턴:

```
const ILGAN_DATA = [
  { key: "gap", name_kr: "갑목", element: "목", trait: "...", categories: { love: "...", money: "...", ... } },
  ... (10개: 갑을병정무기경신임계)
];
```

- 일간 10개 × (trait 1개 + 카테고리 11개 문장) = 121개 문장
- 오행 균형 수식어: 5원소 × {과다/부족} + 균형 1개 = 11개 짧은 문장, 카테고리 해설 뒤에 덧붙임
- 오늘의운(카테고리 미선택) 시: 일간 trait만 표시, 기간 프리픽스 생략(별자리/띠운세와 동일 규칙 — trait 문장에 이미 주어가 있어 프리픽스를 붙이면 주어가 중복됨)

## 히스토리 저장

`entry.mode = 'saju'`:
```
{
  date, mode: 'saju',
  calendarType: 'solar' | 'lunar',
  birthDate, birthTime, timeUnknown, gender,
  dayIlganName,
  category, period
}
```
전체 8자 간지(`pillars`)는 저장하지 않고, 일간 이름(`dayIlganName`, 예: "갑목")만 문자열로 저장한다 — 명식표는 재생성하지 않고 히스토리 목록에는 일간만 표시하면 충분하기 때문.
`renderHistory()`에 사주 분기 추가 (예: "1995-03-12 · 갑목 일간").

## 에러 처리

- 지원 연도 범위(1900~2050) 밖 입력: 에러 메시지 표시, 계산 진행 안 함
- 날짜/시간 미입력 상태로 리딩 시도: 해당 입력란에 포커스, 진행 안 함(기존 띠운세의 `birthYearInput` 미입력 처리와 동일 패턴)
- localStorage 사용 불가 환경: 기록 저장만 건너뛰고 나머지 기능은 정상 동작 (기존 패턴 재사용)

## 테스트 방식 (`tests/saju-calc.test.js`, `node`로 직접 실행)

- `solarLongitude`: 춘분(λ≈0도, 3월 20일경)·하지(λ≈90도, 6월 21일경) 근처 알려진 날짜에서 근사값 검증
- `findSolarTermMoment`: 입춘 날짜가 여러 연도(1900~2050 범위 내 샘플)에서 2/3~2/5 사이에 오는지 범위 검증
- 60갑자 일진 공식: 공개적으로 검증 가능한 기준일 2~3개와 대조 (구현 단계에서 WebFetch로 출처 확인 후 테스트에 고정)
- 년주/월주/시주/대운 규칙표가 60가지 조합을 빠짐없이 순환하는지 (오프바이원 없음)
- 입춘 경계를 걸친 생일(예: 2월 3일 밤 vs 2월 4일 새벽)의 년주가 올바르게 갈리는지
- 음력 변환 테이블: 공개적으로 검증 가능한 음력→양력 변환 사례 몇 개(설날 날짜 등)와 대조
- 시간 모름 → 시주·대운 없이 3주만 계산되고 크래시 없는지
- 대운 순행/역행: 성별×년간 음양 조합 4가지 케이스 모두 검증
