# 규칙 기반 질문 해석 설계

- 타로 모드에 선택 입력 "마음속 질문"(80자). 질문은 서버로 보내지 않고 기기에만 저장.
- `js/question-intent.js`: 키워드 점수로 주제·하위선택·실천 기간·질문 형태(decision/timing/heart/general) 판정. 동점·무점수는 미분류로 두고 직접 선택 유지. 입력하면 기존 주제·하위선택·기간 버튼에 반영하고 "이렇게 읽을게요" 칩을 보여 준다(같은 해석이면 사용자가 고친 선택을 덮어쓰지 않음).
- 결과 상단에 질문 인용과 형태별 한 줄 프레임. 남의 속마음 질문은 "내가 할 수 있는 태도" 쪽으로 돌려 읽는다.
- 안전: 자해·극단적 선택 표현이 있으면 카드를 뽑지 않고 109(자살예방상담전화)·112·119 안내.
- 기록(history)에는 질문 저장, 공유 이미지·링크·텍스트 공유에는 질문을 넣지 않는다.
- 테스트: 11개 주제 예문 55개 분류 정확도, 기간·형태·안전 판정, 문구 품질.
- 한계: 실제 AI가 아니라 질문을 주제에 연결하고 틀을 잡아 주는 수준. 해석 본문은 준비된 카드 문구.
- 범위 밖: 별자리·띠·사주 모드 질문 입력, 외부 AI 연결.
